# English Journey

Wikipediaの記事やニュース動画を活用して、
現地英語の読解力向上を目指す英語学習Webアプリです。

### アプリ概要
・国と地域を選択し、現地のニュースやwikipedia記事を取得する
・カテゴリ選択をし、任意の記事を選択する
・記事をaiに読み読み込ませ、要約採点や選択問題の生成をする
これらによって世界各国の地域や文化を学びつつ英語を学べる、「**そこでの暮らしをイメージしながら学習できる英語アプリ**」になってます。

### 開発背景・目的
開発担当者でワーホリに行く予定のある人がいたが、ある課題があった。
それは日本の教材ではアメリカ英語かイギリス英語しか学べないので現地の英語を聴き取ったり読み取ったりができるのか
という不安であった。そこで現地のニュース動画などを視聴し、学習しようと思っていたがここでも一つ問題がでてきた。
「問題集などがなく自分の実力がどれくらい向上しているのかが分からない。ただ聞いてどこまで理解できているかを確認するだけになってしまっている。」
という問題である。
これを解決しようと現地のニュース動画や記事を取得し、それらをもとにした要約採点や問題出題、正誤判定をしてくれるアプリを作ろうと考えた。
また、これらの悩みはこの担当者だけではなく現地で長期滞在をする予定のある人が誰しもが持つ不安であり、
暮らしていけるかの不安を取り除けるようなアプリは社会的にも需要があると判断し、制作に取り掛かった。

### 主な機能

- 国・地域・カテゴリの選択
- Wikipedia APIを利用した記事の検索・取得
- YouTube APIを利用したニュース動画の取得
- AIによる英文要約の採点
- AIによる英語読解問題の自動生成
- 選択問題の回答判定
